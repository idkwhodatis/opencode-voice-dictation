Voice settings

Saved on your server and shared by your devices. No API key is stored in this browser.

Choose when you finish recording

Stop and review inserts an editable draft into OpenCode. Review, change, delete, or send it using OpenCode's normal controls.

Transcribe and send inserts the transcript and clicks OpenCode's Send button when ready. This sends the entire draft, including any text or attachments already in the composer.

There is no global auto-send switch. Stopping with Ctrl+Space or reaching the recording time limit always leaves a draft for review. Question inputs are review-only.

Speech provider and API key

HTTP sends recordings and your API key in plaintext on the network. Use it only on a trusted local network.

Service limits Advanced

Shared by all devices using this server. New recordings use the saved duration limit, and new requests use the saved service limits. Requests already running keep their original limits. Lowering concurrency blocks new requests until there is room, without cancelling active requests.

1–100 MB per recording; default 20 MB. Here, 1 MB is 1,048,576 bytes. The server's fixed transport cap is 100 MB.
1–3,600 seconds; default 300 (5 minutes). Reaching this limit stops recording for review.
Maximum wait for the speech provider's response: 1–300 seconds; default 60.
1–16 transcription requests at once across all devices; default 2. Additional requests are rejected while busy.
1–1,000 transcription requests started per 60 seconds across all devices; default 10.

Recordings are sent to your saved speech provider using the model above. This service does not save recordings or transcripts.
